# Movie Witcher — Cinematic Redesign

واجهة React/Vite معاد تصميمها لمنصة اكتشاف ومشاهدة الأفلام والمسلسلات. تستخدم الواجهة كتالوج Cinemeta للبحث والبيانات، ومشغّل Vidfast داخل صفحة المشاهدة.

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

## النشر عبر Vercel

ارفع محتويات المشروع إلى مستودع GitHub، ثم أنشئ مشروعاً جديداً في Vercel من ذلك المستودع. يحتوي المشروع على ملف `vercel.json` الذي يحدد أمر البناء ومجلد النشر وإعادة توجيه مسارات تطبيق React.

> ملاحظة: خدمات Cinemeta وVidfast جهات خارجية؛ تعتمد نتائج البحث والمشاهدة على إتاحتها من المتصفح في وقت الاستخدام.
